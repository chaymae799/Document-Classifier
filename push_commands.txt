# Commandes pour pusher le projet sur GitHub

## Étape 1: Configurer Git LFS (si pas encore installé)
git lfs install

## Étape 2: Traquer les fichiers modèles avec LFS
git lfs track "*.pth"
git lfs track "*.pt"
git add .gitattributes

## Étape 3: Ajouter tous les changements
git add .

## Étape 4: Commit
git commit -m "feat: projet complet - CV fine-tuné (61.11%) + NLP mBERT + Gabarits + Fusion multimodale"

## Étape 5: Push vers GitHub
git push origin main

# Note: Si Git LFS n'est pas installé, télécharger depuis https://git-lfs.github.com/
